

# Doctor Appointment System

A full-stack Doctor Appointment System built using the MERN stack (MongoDB, Express.js, React, and Node.js). This application provides a seamless platform for patients to book appointments, doctors to manage their schedules, and administrators to oversee the entire system.

## Features

- User Authentication (JWT)
- Patient Registration & Login
- Doctor Registration & Login
- Browse Available Doctors
- Book Appointments
- Appointment History
- Doctor Dashboard
- Admin Dashboard
- Manage Patients
- Manage Doctors
- Manage Appointments
- Responsive User Interface
- Secure REST APIs
- MongoDB Database Integration

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- HTML
- CSS
- JavaScript
